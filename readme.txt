ITPIO SEARCH
============

Tentang folder ini
------------------
Folder ini berisi halaman pencarian sederhana dengan nama dan logo ITPIO.
Tampilannya terinspirasi antarmuka Perplexity, dengan nama ITPIO dan pencarian Google, serta bisa digunakan di komputer
maupun ponsel.

Isi folder
----------
index.html  Halaman utama ITPIO Search. Tampilan, gaya, dan fungsi pencarian
            berada dalam satu file ini.

Cara menggunakan
----------------
1. Buka index.html menggunakan browser seperti Chrome, Edge, atau Firefox.
2. Ketik kata kunci pada kotak pencarian.
3. Tekan Enter atau pilih tombol pencarian.

Pencarian web diteruskan ke Google, sehingga koneksi internet diperlukan dan
hasilnya akan tampil di situs Google. Folder ini tidak memerlukan instalasi,
server, atau paket tambahan.

Fitur
-----
- Tampilan responsif untuk layar komputer dan ponsel.
- Mode terang dan gelap; pilihan tema disimpan oleh browser jika tersedia.
- Tombol Chat with AI membuka Google Gemini.
- Pintasan ke Google Docs, Drive, Sheets, Slides, Gmail, Calendar, Meet, dan Forms.
- Tombol untuk menghapus kata kunci.
- Tekan / untuk langsung fokus ke kotak pencarian.
- Tekan Escape untuk menghapus kata kunci saat kotak pencarian aktif.
- Tautan bantuan, privasi, Gmail, dan Gambar mengarah ke layanan Google.
